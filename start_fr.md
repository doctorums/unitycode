## Vous voulez votre propre nœud dans le réseau ?

Chaque portail UnityCode est un nœud vivant. Ils peuvent être nombreux et font tous partie d’un même réseau en expansion. Vous pouvez aussi allumer le vôtre.

« Faire un fork », c’est créer votre propre copie de ce monde. Elle deviendra vôtre : modifiez les textes, les couleurs, le ciel, remplissez‑la de votre propre sens. Personne ne possède le réseau — chacun y a sa propre voix.

### De quoi avez‑vous besoin ?

Un compte gratuit sur **GitHub** — c’est là que vit le code des portails. Si vous n’en avez pas, l’inscription ne prend qu’une minute.

### Trois étapes

- Cliquez sur **Fork** — vous aurez votre propre copie du portail.
- Modifiez‑la comme vous le souhaitez : le nom, les textes, les couleurs du ciel.
- Publiez — et votre nœud s’allumera dans le réseau.

N’ayez pas peur de casser quoi que ce soit — c’est votre bac à sable. Si vous voulez comprendre plus en détail ce qui peut être modifié et ce qu’il vaut mieux ne pas toucher, ouvrez **« Comment faire un fork »**.

Bienvenue. Le réseau attend votre fréquence.
